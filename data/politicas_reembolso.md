# Políticas de reembolso — Tienda Demo (ficticia)

Documento de ejemplo para el mini-proyecto RAG. No es política real.

## Plazo

El cliente tiene **30 días** desde la fecha de **entrega** del pedido para solicitar un reembolso.

Si la solicitud se hace después de 30 días desde la entrega, el reembolso se **rechaza por plazo vencido**.

## Estado del pedido

Solo se aceptan reembolsos de pedidos en estado **entregado**.

- Si el pedido está **en tránsito** o **pendiente**, no se aprueba el reembolso.
- Se debe esperar a la entrega o contactar soporte de envíos.

## Monto máximo automático

El reembolso **automático** aplica solo si el monto del pedido es de **$200 USD o menos**.

Si el monto es **mayor a $200 USD**, el caso se **escala a un agente humano**. El bot no puede aprobar ni rechazar de forma definitiva.

## Productos no reembolsables

No se reembolsan:

- Productos digitales (cursos, licencias, descargas)
- Tarjetas de regalo
- Productos personalizados ya fabricados

## Tiempo de procesamiento

Cuando un reembolso es aprobado:

- El dinero se devuelve en **3 a 5 días hábiles** al mismo método de pago.
- El cliente recibe un correo de confirmación.

## Cómo solicitar

Para solicitar un reembolso el cliente debe indicar:

1. Número de pedido (ejemplo: #12345)
2. Motivo breve de la devolución
3. Si el producto fue usado o está sellado

## Contacto

Horario de soporte: lunes a viernes, 9:00 a 17:00 (hora local).

Correo de soporte: soporte@tiendademo.example

Para montos mayores a $200 o casos especiales, el equipo humano responde en un máximo de **48 horas hábiles**.
